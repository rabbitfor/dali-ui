# Focus Navigation

방향키와 Tab을 이용한 포커스 네비게이션이 정상 동작하는지 확인한다.

## 화면 구성

- 상단: 현재 포커스 상태를 표시하는 라벨
- 하단: 2x2 그리드로 배치된 4개의 View (각각 다른 배경색)
- 포커스를 받은 View는 주황색으로 변경됨

```
  [View 1] [View 2]
  [View 3] [View 4]
```

## 테스트 1: Tab 포커스 이동

1. Tab 키를 눌러 View 1에 포커스를 준다
2. **기대 결과**: View 1이 주황색으로 변경, 상단에 "Focused: View 1" 표시
3. Tab을 반복하여 View 2 → View 3 → View 4 순으로 이동한다
4. **기대 결과**: 포커스를 받은 View만 주황색, 나머지는 원래 색상 복귀

## 테스트 2: 방향키 포커스 이동

1. View 1에 포커스를 둔 상태에서 → (Right) 키를 누른다
2. **기대 결과**: View 2로 포커스 이동
3. ↓ (Down) 키를 누른다
4. **기대 결과**: View 4로 포커스 이동
5. ← (Left) 키를 누른다
6. **기대 결과**: View 3으로 포커스 이동
7. ↑ (Up) 키를 누른다
8. **기대 결과**: View 1으로 포커스 이동

## 테스트 3: 포커스 인디케��터

1. Tab 키로 포커스를 이동한다
2. **기대 결과**: 포커스를 받은 View에 포커스 인디케이터(하이라이트 테두리)가 표시됨

## 통과 기준

- Tab으로 순차적 포커스 이동이 가능해야 한다
- 방향키로 2x2 ���리드 내 상하좌우 이동이 가능해야 한다
- 포커스를 가진 View만 주황색으로 표시되어야 한다
- 상단 라벨에 현재 포커스된 View 번호가 정확히 표시되어야 한다
